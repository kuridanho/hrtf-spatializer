# HRTF データセット仕様

Spatializer は **21 方向のステレオ HRIR（頭部インパルス応答）** を WAV ファイルとして読み込みます。SOFA 形式には未対応です。

## ディレクトリ構成

`--dataset-dir`（既定は `./dataset`）の直下に、21 ファイルが揃ったディレクトリを置きます。

```text
dataset/
├── home_impulse_bedroom_441_6/
│   ├── 0_0.wav
│   ├── 100_0.wav
│   ├── 0_100.wav
│   ├── 10_0.wav
│   ├── 0_10.wav
│   ├── …
│   └── 90_0.wav
└── another_room/
    └── …
```

- 親フォルダに複数のデータセットを置けます。GUI のコンボボックスにディレクトリ名が並びます。
- `--dataset-dir` にデータセット自身を指定しても構いません。
- 21 ファイルが 1 つでも欠けると、そのディレクトリはデータセットとして認識されません。

## ファイル名と方向

ファイル名は `L_R` 形式です。1 つ目の数値が左方向、2 つ目の数値が右方向の角度（度）を表します。

| ステム | ラベル | 入力 L ゲイン | 入力 R ゲイン |
|---|---|---:|---:|
| `100_0` | L100 | 1.00 | 0.00 |
| `0_100` | R100 | 0.00 | 1.00 |
| `10_0` | L10 | 0.55 | 0.45 |
| `0_10` | R10 | 0.45 | 0.55 |
| `20_0` | L20 | 0.60 | 0.40 |
| `0_20` | R20 | 0.40 | 0.60 |
| `30_0` | L30 | 0.65 | 0.35 |
| `0_30` | R30 | 0.35 | 0.65 |
| `40_0` | L40 | 0.70 | 0.30 |
| `0_40` | R40 | 0.30 | 0.70 |
| `50_0` | L50 | 0.75 | 0.25 |
| `0_50` | R50 | 0.25 | 0.75 |
| `60_0` | L60 | 0.80 | 0.20 |
| `0_60` | R60 | 0.20 | 0.80 |
| `70_0` | L70 | 0.85 | 0.15 |
| `0_70` | R70 | 0.15 | 0.85 |
| `80_0` | L80 | 0.90 | 0.10 |
| `0_80` | R80 | 0.10 | 0.90 |
| `90_0` | L90 | 0.95 | 0.05 |
| `0_90` | R90 | 0.05 | 0.95 |
| `0_0` | Center | 0.50 | 0.50 |

`30_0` は「左 30°」、`0_30` は「右 30°」です。`100_0` / `0_100` は後方を含む最大角度として扱います。

## 音声フォーマット

| 項目 | 要件 |
|---|---|
| チャンネル数 | **2ch ステレオ固定**（1ch / 多チャンネルはエラー） |
| サンプルレート | データセット内で統一。ストリームの `--sample-rate` と一致必須 |
| 長さ | データセット内で統一（例: 16384 samples） |
| データ型 | float32 / PCM16 など soundfile が読める形式。内部的に float32 へ変換 |
| 値 | 有限値（NaN / Inf 不可） |
| チャンネル | ch0 = 左耳、ch1 = 右耳 |

長さは任意ですが、UPOLS のパーティション数が変わるため、データセットごとに揃えてください。16384 samples @ 44.1 kHz は約 371 ms に相当します。

### 複数テイクの平均

同じ方向を複数回測定した場合、`<stem>(2).wav` を置くと 2 テイクを平均します。

```text
0_0.wav
0_0(2).wav   ← 0_0.wav と平均される
```

- 2 ファイルの長さ・サンプルレートが一致している必要があります。
- `HRTFDataset(..., average_takes=False)` で無効化できます（GUI / CLI からは常に有効）。

## 検証

GUI を起動せずに確認できます。

```bash
# データセットの一覧
spatializer --list-datasets --dataset-dir dataset

# 詳細検証（不足ファイル、長さ、サンプルレート、ピークなど）
python scripts/validate_dataset.py dataset/my_room
```

`validate_dataset.py` は以下を検査します。

- 21 ファイルが存在するか
- すべて 2ch か
- 長さ・サンプルレートが揃っているか
- NaN / Inf が無いか
- 無音（ピークが極端に小さい）でないか

## 測定のヒント

1. 無響室または静かな部屋で、スピーカーを耳から一定距離に置く。
2. スピーカーを 10° 刻み（左右 90°、必要なら 100°）で回転させ、各方向でインパルス応答を録音する。
3. 左右の耳にマイクを装着し、**2ch 同時録音**する。ch0 を左耳、ch1 を右耳にする。
4. スイープ信号を使う場合は、逆フィルタでインパルス応答に変換する（`scipy.signal.fftconvolve` など）。
5. 頭の位置を固定し、各方向で同じ高さ・距離を保つ。
6. 必要に応じてトリミングし、全ファイルを同じ長さに揃える。
7. `scripts/validate_dataset.py` で検証し、`--list-datasets` で認識を確認する。

測定条件（部屋、距離、マイク、被験者）をデータセット名や README に残すと再現性が上がります。

## SOFA / 他形式からの変換

現状 SOFA の直接読み込みはありません。SOFA から変換する場合は、以下の条件を満たす 21 個の WAV を書き出してください。

- 方向は上表の 21 ステムに対応する方位角（正面 0°、左右 10° 刻み、最大 100°）
- 左右の耳のインパルス応答を 2ch にまとめる
- 同じ長さ・サンプルレートにリサンプリングする

`scripts/generate_dummy_dataset.py` の `make_hrir()` が、ファイル名から角度を求める実装例になっています。

## ライセンスと公開

HRTF は測定者・機関・配布元によってライセンスが異なります。特に第三者から入手したデータを公開リポジトリにコミットしないでください。このリポジトリでは `dataset/` と `*.wav` を `.gitignore` で除外しています。
